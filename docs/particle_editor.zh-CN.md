# Particle 粒子编辑器

Particle 编辑器用于查看、预览和编辑粒子系统定义。它面向 `.xml` / `.xml.compiled` 粒子资源，支持发射器、参数轨道、标记、粒子场和系统场。

## 打开方式

1. 打开包含粒子资源的项目。
2. 在项目资源管理器中展开 `粒子`。
3. 点击目标 particle 资源。

编辑器顶部显示：

- 资源 ID。
- 项目内文件路径。

## 主界面组成

- 中央预览视口：实时播放粒子系统。
- 属性面板：编辑资源 ID、发射器、轨道、字段和图像引用。

## 发射器列表

属性面板的 `定义` 区域顶部是发射器下拉框。

操作：

- 选择发射器：切换正在编辑的发射器。
- `添加`：追加新发射器。
- `移除`：删除当前发射器。

发射器显示格式：

- 有名称：`序号. 名称`
- 无名称：`发射器 序号`

## 常规设置

发射器 `常规` 区域包含：

| 字段 | 说明 |
| --- | --- |
| `名称` | 发射器名称。 |
| `图像 ID` | 粒子使用的图像资源 ID。 |
| `图像行` | 图集行索引，从 0 开始。 |
| `图像列` | 图集列索引，从 0 开始。 |
| `图像帧数` | 粒子动画使用的帧数，最小 1。 |
| `发射器类型` | 发射器形状/行为类型。 |
| `动画` | 是否按图像帧动画播放。 |

## 标记设置

发射器 `标记` 区域提供多个布尔开关：

- `随机发射旋转`
- `对齐发射旋转`
- `对齐到像素`
- `系统循环`
- `粒子循环`
- `粒子不跟随`
- `过载时消失`
- `叠加`
- `全屏`
- `仅软件`
- `仅硬件`

这些开关会写回粒子定义中的 flags。

## 参数轨道

Particle 编辑器大量使用浮点参数轨道。每条轨道由一个或多个节点组成。

每个节点包含：

| 字段 | 说明 |
| --- | --- |
| `时间` | 节点时间百分比，范围 0 到 100。 |
| `低值` | 低值。 |
| `高值` | 高值。 |
| `曲线` | 值随时间变化的曲线类型。 |
| `分布` | 低值到高值之间的分布类型。 |

轨道操作：

- `重置`：恢复为默认单节点轨道。
- `添加`：在最后一个节点后添加新节点。
- `复制`：复制当前节点，并把时间向后偏移 1。
- `移除`：删除当前节点；每条轨道至少保留 1 个节点。

节点会按 `时间` 自动排序，数值保留三位小数。

## 轨道分组

发射器参数按区域分组：

| 分组 | 主要轨道 |
| --- | --- |
| `生命周期` | `SystemDuration`、`CrossFadeDuration`、`ParticleDuration` |
| `生成` | `SpawnRate`、`SpawnMinActive`、`SpawnMaxActive`、`SpawnMaxLaunched` |
| `发射器形状` | `EmitterRadius`、`EmitterOffsetX/Y`、`EmitterBoxX/Y`、`EmitterSkewX/Y`、`EmitterPath` |
| `发射` | `LaunchSpeed`、`LaunchAngle` |
| `系统颜色` | `SystemRed/Green/Blue/Alpha/Brightness` |
| `粒子颜色` | `ParticleRed/Green/Blue/Alpha/Brightness` |
| `粒子变换` | `ParticleScale`、`ParticleStretch`、`ParticleSpinAngle`、`ParticleSpinSpeed` |
| `渲染` | `AnimationRate`、`ClipTop/Bottom/Left/Right` |
| `碰撞` | `CollisionReflect`、`CollisionSpin` |

## 粒子场和系统场

`粒子场` 和 `系统场` 都由字段列表组成。

字段内容：

| 字段 | 说明 |
| --- | --- |
| `场类型` | 字段类型。 |
| `x` | X 方向参数轨道。 |
| `y` | Y 方向参数轨道。 |

操作：

- `添加`：新增字段。
- `移除`：删除当前字段。

粒子场通常作用于单个粒子，系统场通常作用于系统整体或发射器上下文。

## 图像引用检查

属性面板的 `图像引用` 区域显示：

- 粒子定义中引用的图像 ID。
- 已解析到项目图像的 ID。
- 缺失图像 ID。

如果预览没有贴图或粒子不可见，优先检查：

1. 发射器 `图像 ID` 是否为空。
2. 图像 ID 是否存在于项目图像资源中。
3. 图像行、列和帧数是否匹配图集设置。

## 预览

粒子预览会持续运行当前定义。

视口操作：

- 鼠标滚轮缩放。
- 中键拖动画布。
- 双击重置视图。

修改发射器、轨道或字段后，预览会刷新。

## 撤销与重做

支持撤销/重做：

- 资源 ID 修改。
- 发射器增删。
- 发射器常规字段和 flags 修改。
- 参数轨道和节点修改。
- 粒子场/系统场修改。

快捷键：

- 撤销：Windows/Linux `Ctrl+Z`，macOS/iOS `Command+Z`
- 重做：Windows/Linux `Ctrl+Y` 或 `Ctrl+Shift+Z`，macOS/iOS `Command+Y` 或 `Command+Shift+Z`

## 保存与导出

保存入口：

- `文件 -> 保存当前文件`
- `文件 -> 保存全部文件`

导出入口：`文件 -> 导出当前文件...`

导出格式：

- 源格式：`.xml`
- 编译格式：`.xml.compiled`

预览导出：

- `文件 -> 导出预览...`
- 粒子编辑器使用时间范围导出。
- 可设置起始秒、终止秒、导出到结束、FPS 和画布倍率。

## 常见问题

### 为什么修改轨道后文件没有明显变化？

如果轨道只有一个默认节点，保存时会被规范化为空轨道，以保持资源文件简洁。非默认值会正常写入。

### 为什么粒子完全看不到？

常见原因：

- 发射器没有图像 ID。
- 图像 ID 缺失。
- `SpawnRate`、生命周期或透明度轨道使粒子不可见。
- 选择了错误的图像行列或帧数。
