# 字体编辑器

字体编辑器用于查看和编辑 Font 资源。EffectViewer 支持图片字体描述和 TrueType 字体两类资源。

## 打开方式

1. 打开包含字体资源的项目。
2. 在项目资源管理器中展开 `字体`。
3. 点击任意字体资源。

编辑器顶部显示：

- 当前字体资源 ID。
- 项目内字体路径。

## 支持的字体来源

| 类型 | 常见路径/扩展名 | 说明 |
| --- | --- | --- |
| 图片字体 | `.txt` 字体描述文件 | 通常由 `resources.xml` 或资源文件夹导入，描述字形图层和贴图。 |
| TrueType 字体 | `.ttf` | 可单文件导入，用字体文件动态生成预览。 |

## 预览区域

图片字体：

- 显示解析到的字体纹理图。
- 如果有多个纹理图，可通过右上角下拉框切换。
- 如果没有解析到纹理图，会显示“没有解析到字体纹理图”。

TrueType 字体：

- 显示自动生成的预览文本。
- 预览文本会包含英文、数字；支持中文字符时也会包含中文样例。

视口操作：

- 鼠标滚轮缩放。
- 中键拖动画布。
- 双击重置缩放和平移。

## 属性面板

入口：编辑器右上角 `布局 -> 属性`。

通用字段：

| 字段 | 说明 |
| --- | --- |
| `ID` | 字体资源 ID。Lua 脚本或 reanim 文本轨道引用字体时使用。 |
| `默认字号` | 字体文件声明的默认字号。 |
| `字号` | 字体当前字号或描述字号。 |
| `上升` | 字体 ascender 指标。 |
| `上升留白` | 字体上升留白。 |
| `高度` | 字体高度指标。 |
| `行距偏移` | 行距偏移量。 |
| `图层` | 图片字体图层数量。 |
| `字形` | 解析到的字形数量。 |
| `纹理数` | 可预览的字体纹理数量。 |

TrueType 可编辑字段：

| 字段 | 范围 | 说明 |
| --- | --- | --- |
| `字体大小` | 1 到 256 | 生成预览纹理时使用的字号。 |
| `边框大小` | 0 到 64 | 生成预览纹理时使用的描边宽度。 |

图片字体额外信息：

- `纹理图`：显示当前选中纹理的图层、图像 ID、纹理尺寸和图像名。
- `图层`：列出每个图层的图像名、解析图像、字号、上升、高度、间距和字形数。

## 修改字体 ID

操作步骤：

1. 在属性面板的 `ID` 输入新 ID。
2. 输入框失焦后应用修改。
3. 保存当前文件或保存项目。

规则：

- ID 会自动去掉首尾空白。
- ID 不能为空。
- 如果和同项目其他字体冲突，会自动尝试追加 `_2`、`_3` 等后缀。

影响：

- 项目索引会更新。
- 已写在脚本或动画文本轨道中的旧字体 ID 不会自动替换。

## 调整 TrueType 预览

TrueType 字体可直接调整：

- `字体大小`
- `边框大小`

修改后预览会刷新，并在保存后写入项目清单。

注意：

- 这些参数影响 EffectViewer 内的字体预览和运行时生成的纹理。
- 它们不会改写 `.ttf` 文件本身。

## 撤销与重做

支持撤销/重做：

- 字体 ID 修改。
- TrueType 字体大小修改。
- TrueType 边框大小修改。

快捷键：

- 撤销：Windows/Linux `Ctrl+Z`，macOS/iOS `Command+Z`
- 重做：Windows/Linux `Ctrl+Y` 或 `Ctrl+Shift+Z`，macOS/iOS `Command+Y` 或 `Command+Shift+Z`

## 保存与导出

保存入口：

- `文件 -> 保存当前文件`
- `项目 -> 保存项目`
- `文件 -> 保存全部文件`

字体编辑器的可编辑内容保存在项目清单中。

导出入口：`文件 -> 导出当前文件...`

导出会复制当前字体文件到你选择的位置。

## 常见问题

### 显示“无法读取字体描述文件”

可能原因：

- 字体文件路径不存在。
- 图片字体描述格式不符合解析器要求。
- 图片字体引用的纹理图缺失。

可以在属性面板查看加载错误详情，并检查项目清单中的 `path` 是否正确。

### 图片字体没有预览纹理？

图片字体需要能从描述文件解析出图层，并且图层引用的图像资源需要存在于项目中。检查 `图层` 和 `纹理图` 信息是否为空。

### TrueType 字体调整后文件变大了吗？

不会。字体大小和边框大小只记录在项目清单中，不会修改 `.ttf` 文件。
