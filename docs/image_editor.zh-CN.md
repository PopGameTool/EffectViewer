# 图像编辑器

图像编辑器用于查看和编辑项目中的 Image 资源。它主要处理图像 ID、图集行列数和当前预览帧。

## 打开方式

1. 打开或导入包含图像资源的项目。
2. 在项目资源管理器中展开 `图像`。
3. 点击任意图像资源。

编辑器顶部显示：

- 当前图像资源 ID。
- 项目内图像路径。

## 预览区域

主区域显示图像或图集当前帧。

视口操作：

- 鼠标滚轮：缩放。
- 中键拖动：平移。
- 左键拖动：在非可拖拽编辑器中也会平移。
- 双击：重置缩放和平移。

可通过主菜单 `视图 -> 浅色背景` 或 `视图 -> 深色背景` 切换预览背景。

## 属性面板

入口：编辑器右上角 `布局 -> 属性`。

可编辑字段：

| 字段 | 说明 |
| --- | --- |
| `ID` | 图像资源 ID。脚本、粒子和动画引用图像时使用该 ID。 |
| `行数` | 图集纵向分割数量，最小 1，最大 128。 |
| `列数` | 图集横向分割数量，最小 1，最大 128。 |
| `帧` | 当前预览帧索引，从 0 开始。 |

只读信息：

| 字段 | 说明 |
| --- | --- |
| `单元格` | `行数 * 列数`。 |
| `行` | 当前帧所在行，从 0 开始。 |
| `列` | 当前帧所在列，从 0 开始。 |

## 编辑图集行列

如果图像是序列帧图集：

1. 将 `行数` 设置为图集纵向帧数。
2. 将 `列数` 设置为图集横向帧数。
3. 用 `帧` 切换查看每个单元格。
4. 保存当前文件或保存项目。

示例：

- 一张 4 行 5 列的图集应设置为 `行数 = 4`、`列数 = 5`。
- 总帧数为 20，帧索引范围是 `0` 到 `19`。

## 修改图像 ID

操作步骤：

1. 在属性面板的 `ID` 输入新 ID。
2. 输入框失焦后会应用修改。
3. 保存项目或当前文件。

规则：

- ID 会自动去掉首尾空白。
- ID 不能为空。
- 如果输入的 ID 与同项目其他图像冲突，编辑器会尝试追加 `_2`、`_3` 等后缀。

影响：

- 图像 ID 修改后，项目索引会更新。
- 已经写在 reanim、particle、trail 或 Lua 脚本中的旧 ID 不会自动批量替换，需要手动同步。

## 撤销与重做

支持撤销/重做：

- 图像 ID 修改。
- 行数修改。
- 列数修改。

快捷键：

- 撤销：Windows/Linux `Ctrl+Z`，macOS/iOS `Command+Z`
- 重做：Windows/Linux `Ctrl+Y` 或 `Ctrl+Shift+Z`，macOS/iOS `Command+Y` 或 `Command+Shift+Z`

## 保存与导出

保存入口：

- `文件 -> 保存当前文件`
- `项目 -> 保存项目`
- `文件 -> 保存全部文件`

图像编辑器的修改保存在项目清单中，不会改写原始图片像素。

导出入口：`文件 -> 导出当前文件...`

导出会复制当前图像文件到你选择的位置。

## 常见问题

### 修改行列数后预览帧跳变？

编辑器会自动限制当前帧在合法范围内。如果新的 `行数 * 列数` 小于旧帧索引，当前帧会被夹到最后一帧。

### 保存时报“图像 ID 不能为空”？

属性面板中 `ID` 不能为空。输入一个非空 ID 后再保存。

### 图集从第几帧开始？

图像编辑器的帧索引从 0 开始，显示的行列也从 0 开始。
