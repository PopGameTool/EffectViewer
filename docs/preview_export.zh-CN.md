# 预览与导出

EffectViewer 支持两类导出：

- `导出当前文件`：把当前资源文件导出到项目外。
- `导出预览`：把当前编辑器的渲染预览导出为图片或动画。

本文重点说明 `文件 -> 导出预览...`。

## 打开导出预览对话框

入口：`文件 -> 导出预览...`

快捷键：

- Windows/Linux：`Ctrl+E`
- macOS/iOS：`Command+E`

可导出预览的编辑器：

- Image
- Font
- Reanim
- Particle
- Trail
- ShowCase

欢迎页和项目页不能导出预览。

## 导出格式

| 格式 | 输出 | 适合场景 |
| --- | --- | --- |
| `Png` | 单张 `.png` | 静态预览、当前帧截图。 |
| `PngSequenceZip` | 包含多张 PNG 的 `.zip` | 需要后期合成或逐帧检查。 |
| `Gif` | `.gif` 动画 | 快速分享、兼容性优先。 |
| `Webp` | `.webp` 动画 | 更高压缩率或 Web 使用。 |

## 通用选项

| 选项 | 说明 |
| --- | --- |
| `格式` | 选择导出格式。 |
| `画布倍率` | 输出分辨率倍率，范围 0.1 到 16。 |
| `FPS` | 动画导出帧率，范围 1 到 240；静态 PNG 不使用该项。 |
| `时长` | 当编辑器没有可定位时间线时，动画导出的总时长。 |

画布倍率示例：

- `1`：按预览画布基础尺寸导出。
- `2`：导出宽高各 2 倍的图像。
- `0.5`：导出宽高各 0.5 倍的图像。

## Reanim 的帧范围导出

Reanim 编辑器会提供时间线选项：

- `完整时间线`
- 可识别的轨道/动画层范围

可设置：

| 选项 | 说明 |
| --- | --- |
| `时间线` | 选择完整时间线或某个图层范围。 |
| `起始帧` | 导出开始帧，显示为从 1 开始。 |
| `终止帧` | 动画格式的结束帧，显示为从 1 开始。 |

注意：

- UI 中的帧范围从 1 开始显示。
- Reanim 编辑器内部帧索引从 0 开始。
- 选择时间线后，起始帧和终止帧会自动填充。
- PNG 静态导出只使用起始帧。

## Particle 和 Trail 的时间范围导出

Particle 和 Trail 使用秒数范围。

可设置：

| 选项 | 说明 |
| --- | --- |
| `起始秒` | 从第几秒开始捕获。 |
| `终止秒` | 捕获到第几秒结束。 |
| `导出到结束` | 动画导出时一直导出到模拟结束或最大时长限制。 |

限制：

- 秒数会被限制在 0 到最大允许时间内。
- 若终止秒小于起始秒，会自动修正。
- 动画导出会按 FPS 计算帧数。

## Image 和 Font 的导出

Image 和 Font 通常是静态预览：

- PNG：导出当前预览帧。
- 动画格式：若没有时间线选项，会使用 `时长` 和 `FPS` 捕获重复或静态帧。

图像编辑器中选择的 `帧` 会影响导出的静态预览。

## ShowCase 的导出

ShowCase 导出会：

1. 创建独立运行世界。
2. 重新运行当前脚本。
3. 捕获脚本场景帧。

建议：

- 导出前先点击 `运行`，确认日志没有错误。
- 如果脚本依赖随机数，导出结果可能与当前播放状态不同。
- 如果脚本没有可持续更新的帧提供器，动画导出可能表现为静态帧。

## 文件名规则

导出预览默认文件名会根据编辑器标题和范围生成。

示例：

- `fire-f0001.png`
- `fire-f0001-f0024.gif`
- `trail-t0s-2s.webp`
- `particle-t1.5s-end-frames.zip`

扩展名由导出格式决定：

- PNG：`.png`
- PNG 序列：`.zip`
- GIF：`.gif`
- WebP：`.webp`

## 导出进度

导出过程中会显示进度对话框，可能包含：

- 捕获帧。
- 渲染帧。
- 栅格化帧。
- 编码图像。
- 写入帧。

导出完成后，状态栏会提示导出成功或失败原因。

## 常见问题

### 为什么动画导出帧数很多？

帧数大致等于 `时长 * FPS` 或选中帧范围长度。降低 FPS、缩短时长或缩小范围可以减少帧数。

### 为什么 GIF 颜色不如 PNG？

GIF 格式本身颜色能力有限。需要更好质量时可选择 PNG 序列或 WebP。

### 为什么导出失败？

常见原因：

- 当前编辑器没有可导出的预览。
- 脚本运行失败。
- 目标路径不可写。
- 画布倍率过高导致内存压力过大。
- 当前资源定义无法编码或渲染。
