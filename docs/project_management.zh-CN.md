# 项目管理

项目是 EffectViewer 的资源容器。一个项目目录至少包含 `project.effectproj.json`，并通常包含 `assets/`、`scripts/` 等资源文件夹。

## 新建项目

入口：`项目 -> 新建项目...`

快捷键：

- Windows/Linux：`Ctrl+Shift+N`
- macOS/iOS：`Command+Shift+N`

操作步骤：

1. 点击 `项目 -> 新建项目...`。
2. 在 `名称` 输入框填写项目名。
3. 点击 `创建`。

结果：

- 应用会在私有项目目录下创建一个唯一的项目文件夹。
- 项目清单会写入 `project.effectproj.json`。
- 当前工作区切换到新项目。

注意事项：

- 项目名为空时会使用默认的“未命名效果项目”。
- 如果当前有未保存文档，系统会先询问是否保存、放弃或取消。

## 打开项目

入口：`项目 -> 打开项目...`

快捷键：

- Windows/Linux：`Ctrl+O`
- macOS/iOS：`Command+O`

打开项目对话框列出应用私有项目目录中已有的 EffectViewer 项目。列表按最近修改时间排序。

操作步骤：

1. 点击 `项目 -> 打开项目...`。
2. 在列表中选择项目。
3. 点击 `打开`。

对话框中的项目项还提供：

- `重命名`：修改项目显示名，并同步项目文件夹安全名称。
- `删除`：删除该内部项目文件夹。

## 重命名项目

入口：`项目 -> 打开项目...` 对话框中的 `重命名`。

操作步骤：

1. 打开项目列表。
2. 点击目标项目右侧的 `重命名`。
3. 输入新名称。
4. 点击 `重命名`。

结果：

- `project.effectproj.json` 中的 `name` 会更新。
- 项目文件夹名会按新名称生成安全名称；如有冲突会自动追加序号。

限制：

- 只能管理应用私有项目目录中的项目。
- 指向私有项目目录外部的路径不会被重命名。

## 删除项目

入口：`项目 -> 打开项目...` 对话框中的 `删除`。

删除会移除整个项目文件夹，且无法撤销。确认前请确保已经导出 Zip 或备份。

操作步骤：

1. 打开项目列表。
2. 点击目标项目右侧的 `删除`。
3. 阅读确认对话框。
4. 点击 `删除`。

限制：

- 只能删除应用私有项目目录中的项目。
- 删除会移除项目清单和所有项目内资源文件。

## 保存项目

入口：`项目 -> 保存项目`

快捷键：

- Windows/Linux：`Ctrl+Alt+S`
- macOS/iOS：`Command+Alt+S`

保存项目会写入项目清单，并接受图像、字体和资源 ID 等随清单保存的修改。

保存前会校验：

- 图像 ID 不能为空。
- 字体 ID 不能为空。
- reanim、particle、trail 的资源 ID 不能为空。

## 导入项目 Zip

入口：`项目 -> 导入项目 Zip...`

用途：导入由 EffectViewer 导出的完整项目包，或包含 `project.effectproj.json` 的项目 Zip。

操作步骤：

1. 点击 `项目 -> 导入项目 Zip...`。
2. 选择 `.zip` 文件。
3. 等待导入进度完成。

导入规则：

- Zip 中必须包含 `project.effectproj.json`。
- 清单可以在 Zip 根目录，也可以在某个子目录内。
- 如果清单在子目录，导入时只提取该子目录下的项目内容。
- 项目会被复制到应用私有项目目录，并自动生成不冲突的项目文件夹。

安全限制：

- Zip 内不能包含绝对路径。
- Zip 内不能包含 `..` 形式的路径穿越。
- 导入失败时，未完成的项目目录会被清理。

## 导出项目 Zip

入口：`项目 -> 导出项目 Zip...`

用途：打包当前内部项目，便于备份、迁移或分享。

操作步骤：

1. 打开要导出的项目。
2. 点击 `项目 -> 导出项目 Zip...`。
3. 选择保存位置和文件名。

导出前行为：

- 当前项目会先保存清单。
- 所有项目目录内文件都会被压缩。
- 如果打开的编辑器有未保存修改，导出前会尝试保存这些文档。

限制：

- 只能导出应用私有项目目录中的项目。
- 当前项目必须存在有效的项目根目录。

## 项目清单结构

`project.effectproj.json` 主要字段：

```json
{
  "version": 2,
  "name": "My Effect Project",
  "images": [],
  "fonts": [],
  "reanims": [],
  "particles": [],
  "trails": [],
  "showcases": []
}
```

每个资源项通常包含：

- `id`：资源 ID。
- `path`：项目内相对路径。

图像还包含：

- `alphaPath`：可选 alpha 伴随图。
- `alphaOnly`：是否为仅 alpha 图像。
- `rows`、`cols`：图集行列数。

TrueType 字体还包含：

- `trueType`：是否按 TTF 处理。
- `fontSize`：预览字号。
- `borderSize`：预览描边。
