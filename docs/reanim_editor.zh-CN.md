# Reanim 动画编辑器

Reanim 编辑器用于查看、预览和编辑 `.reanim` / `.reanim.compiled` 动画定义。它支持轨道、帧、变换、时间线选择、轨道可见性、补间元数据和预览导出。

## 打开方式

1. 打开包含动画资源的项目。
2. 在项目资源管理器中展开 `动画`。
3. 点击目标 reanim 资源。

编辑器顶部显示：

- 资源 ID。
- 项目内文件路径。

## 主界面组成

- 中央预览视口：显示当前动画预览。
- 属性面板：显示结构信息、当前帧变换、补间、图像引用和错误信息。
- 底部时间线：显示轨道和帧，可选择帧、切换轨道可见性、播放动画。

## 预览视口

常用操作：

- 鼠标滚轮：缩放。
- 中键拖动：平移。
- 双击：重置视图。
- 开启 `自由变换` 后，可拖拽选中帧对象。

视口背景：

- `视图 -> 浅色背景`
- `视图 -> 深色背景`

## 时间线

时间线由左侧轨道列表和右侧帧单元格组成。

点击操作：

- 点击帧头：选择该帧。
- 点击轨道名：选择该轨道当前帧。
- 点击单元格：选择指定轨道和指定帧。
- 点击轨道名前的可见性框：切换该轨道是否参与预览。

单元格标记：

| 标记 | 含义 |
| --- | --- |
| `I` | 当前帧有图像引用。 |
| `*` | 当前帧有内容，但不一定有图像。 |
| `T` | 当前帧属于补间范围。 |

右上方时间线控件：

| 控件 | 说明 |
| --- | --- |
| 图层下拉框 | 切换完整时间线或按轨道/动画层预览。 |
| `FPS` | 设置动画预览和导出的帧率，范围 1 到 240。 |
| `播放` | 开始或暂停预览播放。 |
| `自由变换` | 允许在视口中拖拽当前选中帧的变换。 |

## 添加和移除轨道

入口：编辑器右上角 `动画 -> 添加轨道` / `动画 -> 移除轨道`

添加轨道：

- 在当前动画末尾追加轨道。
- 新轨道帧数会与当前动画帧数一致。
- 第一帧使用默认可见变换，其余帧使用默认空变换。

移除轨道：

- 需要至少保留 1 条轨道。
- 会移除当前选中轨道。
- 相关补间元数据会同步调整。

## 添加和移除帧

入口：编辑器右上角 `动画 -> 添加帧` / `动画 -> 移除帧`

添加帧：

- 在当前选中帧之后插入新帧。
- 所有轨道都会插入一帧。
- 补间元数据会随帧位置更新。

移除帧：

- 需要至少保留 1 帧。
- 会从所有轨道移除当前选中帧。
- 相关补间元数据会同步调整。

## 编辑当前帧变换

属性面板的 `变换` 区域针对当前选中轨道和帧生效。

资源字段：

| 字段 | 说明 |
| --- | --- |
| `轨道名称` | 当前轨道名称。 |
| `图像 ID` | 当前帧绑定的图像 ID。 |
| `字体` | 当前帧使用的字体 ID。 |
| `文本` | 当前帧显示的文本内容。 |

数值字段：

| 字段 | 说明 |
| --- | --- |
| `X` / `Y` | 平移位置。 |
| `缩放 X` / `缩放 Y` | 缩放。 |
| `倾斜 X` / `倾斜 Y` | 旋转/倾斜相关参数。 |
| `帧` | 图集帧索引。 |
| `透明度` | 透明度。 |
| `可见` | 当前帧是否可见。 |

注意：

- 如果当前帧属于补间范围，编辑器会禁用直接变换编辑。
- 修改文本框后，失焦会应用数值。
- 轨道名称修改会同步影响图层列表和补间显示名称。

## 自由变换

开启条件：

- 当前是 reanim 编辑器。
- 已选择轨道和帧。
- 当前帧不是补间帧。
- 当前帧可见。

操作方式：

- 拖拽对象内部：移动。
- 拖拽方形控制点：缩放。
- 拖拽菱形控制点：倾斜。

自由变换会直接修改当前帧的变换参数，并标记文档为未保存。

## 补间元数据

补间区域提供：

- `检测`：根据当前帧数据推断补间元数据。
- `添加`：为当前轨道和当前帧附近创建补间。
- `全部烘焙`：把所有补间结果写入帧数据，并清空补间元数据。

选中补间后可编辑：

| 字段 | 说明 |
| --- | --- |
| `轨道` | 补间所在轨道序号。 |
| `轨道名称` | 只读显示轨道名称。 |
| `起始帧` | 补间开始帧。 |
| `终止帧` | 补间结束帧。 |
| `锚点 X` / `锚点 Y` | 补间锚点。 |

补间按钮：

| 按钮 | 说明 |
| --- | --- |
| `关键帧` | 将当前补间中间帧拆为关键帧。 |
| `烘焙` | 把选中补间写入帧数据并移除该补间。 |
| `移除` | 删除选中补间元数据。 |

提示：

- 补间元数据保存在项目清单的 reanim 项中。
- 导出或保存 `.reanim` 时，当前帧数据会按编辑结果编码。

## 图像引用检查

属性面板的 `图像引用` 区域显示：

- `引用`：动画文件中请求的图像 ID。
- `已解析`：项目中能找到的图像资源。
- `缺失`：动画引用但项目中不存在的图像 ID。

如果预览缺贴图，先检查这里的缺失列表，再导入或修正对应图像 ID。

## 错误信息

属性面板的 `错误` 区域显示文件分析错误，例如文件不存在、格式无法解析等。

## 撤销与重做

支持撤销/重做：

- 资源 ID 修改。
- 轨道/帧增删。
- 变换修改。
- 补间检测、添加、删除、烘焙。
- 时间线结构相关修改。

快捷键：

- 撤销：Windows/Linux `Ctrl+Z`，macOS/iOS `Command+Z`
- 重做：Windows/Linux `Ctrl+Y` 或 `Ctrl+Shift+Z`，macOS/iOS `Command+Y` 或 `Command+Shift+Z`

## 保存与导出

保存入口：

- `文件 -> 保存当前文件`
- `文件 -> 保存全部文件`

导出入口：`文件 -> 导出当前文件...`

导出格式：

- 源格式：`.reanim`
- 编译格式：`.reanim.compiled`

预览导出：

- `文件 -> 导出预览...`
- 可选择完整时间线或可识别的图层范围。
- 支持 PNG、PNG 序列 Zip、GIF、WebP。

## 常见问题

### 为什么当前帧不能编辑？

当前帧可能位于补间范围内。你可以先把该帧设为关键帧，或烘焙/删除对应补间。

### 为什么预览没有贴图？

检查 `图像引用 -> 缺失`。如果缺失图像 ID，导入对应图片，或修改帧的 `图像 ID`。

### 为什么修改 FPS 后动画速度改变？

`FPS` 会影响预览播放速度和 reanim 导出的默认帧率。它代表每秒播放多少帧。
