# Trail 轨迹编辑器

Trail 编辑器用于查看、预览和编辑拖尾/轨迹资源。它面向 `.trail` / `.trail.compiled` 文件，核心参数包括图像、最大点数、最小点距离、循环、宽度曲线、透明度曲线和时长。

## 打开方式

1. 打开包含轨迹资源的项目。
2. 在项目资源管理器中展开 `轨迹`。
3. 点击目标 trail 资源。

编辑器顶部显示：

- 资源 ID。
- 项目内文件路径。

## 主界面组成

- 中央预览视口：显示轨迹路径和拖尾效果。
- 属性面板：编辑轨迹定义、图像引用和错误信息。

## 基础设置

属性面板的 `定义` 区域包含：

| 字段 | 说明 |
| --- | --- |
| `图像 ID` | 轨迹使用的图像资源 ID。 |
| `最大点数` | 轨迹最多保留的点数，范围 2 到系统最大值。 |
| `最小距离` | 新点之间的最小距离，最小 0。 |
| `循环` | 是否循环播放轨迹。 |

建议：

- 如果轨迹断裂或过短，适当增加 `最大点数`。
- 如果轨迹点过密导致形状抖动，增加 `最小距离`。
- 如果预览没有纹理，检查 `图像 ID` 是否存在。

## 参数轨道

Trail 使用浮点参数轨道控制宽度、透明度和时长。

轨道列表：

| 轨道 | 说明 |
| --- | --- |
| `WidthOverLength` | 沿轨迹长度方向的宽度变化。 |
| `WidthOverTime` | 随时间变化的宽度。 |
| `AlphaOverLength` | 沿轨迹长度方向的透明度变化。 |
| `AlphaOverTime` | 随时间变化的透明度。 |
| `TrailDuration` | 轨迹持续时间。 |

每条轨道由节点组成：

| 字段 | 说明 |
| --- | --- |
| `时间` | 节点时间百分比，范围 0 到 100。 |
| `低值` | 低值。 |
| `高值` | 高值。 |
| `曲线` | 值随时间变化的曲线类型。 |
| `分布` | 低值到高值之间的分布类型。 |

轨道操作：

- `重置`：恢复默认节点。
- `添加`：新增节点。
- `复制`：复制当前节点。
- `移除`：删除当前节点；每条轨道至少保留 1 个节点。

## 图像引用检查

属性面板的 `图像引用` 区域显示：

- 轨迹定义引用的图像 ID。
- 已解析图像。
- 缺失图像。

如果预览中轨迹没有贴图或显示异常，先检查缺失列表。

## 预览

Trail 预览会用当前定义生成示例路径。

视口操作：

- 鼠标滚轮缩放。
- 中键拖动画布。
- 双击重置视图。

修改基础设置或轨道后，预览会刷新。

## 撤销与重做

支持撤销/重做：

- 资源 ID 修改。
- 图像 ID 修改。
- 最大点数、最小距离、循环修改。
- 宽度、透明度和时长轨道修改。

快捷键：

- 撤销：Windows/Linux `Ctrl+Z`，macOS/iOS `Command+Z`
- 重做：Windows/Linux `Ctrl+Y` 或 `Ctrl+Shift+Z`，macOS/iOS `Command+Y` 或 `Command+Shift+Z`

## 保存与导出

保存入口：

- `文件 -> 保存当前文件`
- `文件 -> 保存全部文件`

导出入口：`文件 -> 导出当前文件...`

导出格式：

- 源格式：`.trail`
- 编译格式：`.trail.compiled`

预览导出：

- `文件 -> 导出预览...`
- Trail 编辑器使用时间范围导出。
- 可设置起始秒、终止秒、导出到结束、FPS 和画布倍率。

## 常见问题

### 轨迹太粗或太细？

调整 `WidthOverLength` 和 `WidthOverTime`。如果只需要常量宽度，保留一个节点并设置相同的低值/高值。

### 轨迹很快消失？

检查 `TrailDuration` 轨道和 `循环` 设置。时长过短会导致轨迹快速淡出或结束。

### 保存时报轨道错误？

轨道节点会被编码到 trail 文件中。检查节点时间是否在 0 到 100，低值/高值是否为合理数字。
